📘 Algebra

What is Algebra?

Algebra is a branch of mathematics that uses letters and symbols to represent numbers. These letters are called variables.

Example

If x + 5 = 12, then:

x = 7

Key Points

  • Variables represent unknown numbers.
  • Expressions contain numbers and variables.
  • Equations show that two expressions are equal.
  • Always simplify before solving.
