📘 Quadratic Equations

What is a Quadratic Equation?

A quadratic equation is an equation of degree 2. It is usually written as:

ax² + bx + c = 0

where a ≠ 0.

Example

x² − 5x + 6 = 0

Factoring:

(x − 2)(x − 3) = 0

Therefore:

x = 2 or x = 3
